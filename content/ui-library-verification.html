Evidence & boundaries

What this review establishes

Automated checks · passed

  • 432 suites / 5,276 tests; coverage: 97.39% statements, 91.39% branches, 92.51% functions, 97.39% lines.
  • 36 pre-login Chromium Playwright checks.
  • TypeScript, ESLint, artifact integrity, ownership, theme, image and locale/message checks.
  • Six ownership tests and six bundle-gate tests.
  • Next.js production build and eight frozen initial-route budgets plus CSS.

Manual browser scope

  • Fresh same-account desktop and mobile captures, including loaded lists, forms, empty states and media dialogs.
  • Photo viewer opened and Next navigation exercised on both versions; mobile details expanded and date calendar opened without changing values.
  • Mobile contact return action, filter modal and life-answer form opened on both origins.
  • FAQ answer expanded on both versions. Candidate French selection updated How It Works immediately and persisted into the home route, then English was restored.
  • Candidate theme applied immediately and survived reload; light theme was restored. Captured candidate mobile document widths stayed within the tested viewport.

Read-only browsing did not create, save, upload, share, approve or delete records.

Still to accept

  • Latest named Figma spacing/typography variable reconciliation: live Figma read was quota-limited; designer sign-off remains pending.
  • Authenticated automated transactional suite not run: controlled credentials/fixtures were not supplied. Read-only browser checks do not prove saves, deletion, sharing permissions or provider handshakes.
  • Large uploads, camera/microphone recording, real mobile devices and all nine locales are not newly accepted by this review.
  • Settings/billing and sensitive account screens omitted from public captures. Public pricing is informational only.
  • Origin/CDN media failures can differ between localhost and Vercel; a baseline video failed to load. Those failures are not classified as integration regressions here.
  • Production LCP/INP/CPU and network timings not measured. Local screenshots use the dev server; production bundles were measured separately.
  • Gifts, concierge, billing and other previously partial business features remain partial; a restyled screen does not complete them.

One reusable presentation system

What changed, what stays in the app

Library

Tokens, spacing/type roles, controls, cards, dialogs, menus, navigation, media and bulk-action presentation. Inter body, Literata SemiBold headings, text-only logo, light/dark themes and shared component dimensions.

Application

Next Image/Link, translations, APIs, forms, Redux, permissions, recording/transcription, partial dates, virtualized geometry and documented sticky/safe-area layouts.

Cleanup

Removed the 12-file local kitchen sink, nine presentation-only wrappers and two UI-only menu hooks. Ownership checks prevent reintroducing the removed patterns. Private library packages remain private.
